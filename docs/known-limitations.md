# Known limitations

- Static files cannot deliver uploads or finalize manual evaluation.
- Remote playback requires network/host policy.
- Successful archive models retain temporary roots until process exit.
- Some nested diagnostics lack exact YAML line/column locations.
- There is no complete writer and no writer/full conformance claim.
- Browser coverage should expand from the current adversarial core to every
  question type across reload and mobile/HTTP variants.
